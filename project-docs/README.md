# 配方笺项目说明网页

独立静态文档，依据 2026-10-12 当前业务代码整理。仅提供文档，不读取健康数据库，不请求业务 API，不调用模型，无第三方运行依赖。

双击 `启动说明网页.cmd`，或在此目录运行 `node server.cjs`，打开 http://127.0.0.1:8790。需要 Node.js 18+。启动器后台运行服务，重复启动复用已运行网页。也可双击 index.html 离线阅读。

- 业务应用仍使用 8765，管理员仍使用 8765/admin。
- index.html：文档正文、完整 PRD、功能拆解与版本记录。
- styles.css：独立页面样式、移动端与打印。
- app.js：搜索、导航、PRD Markdown 导出、四张 SVG 流程图和 Mermaid 源码。
- server.cjs：仅监听 127.0.0.1:8790，只提供三个白名单静态资源。
- PRD.md：本次导出的 Markdown 快照，页面正文更新后需重新导出。

点击“下载 PRD”导出当前正文为 Markdown；流程图可以下载 SVG 和 .mmd。所有资料是静态快照，业务改动后需要同步编辑文档与流程图。

当前原工程没有 Git / CHANGELOG，不编造产品版本。网页 1.0.0 是本说明页版本；产品功能演进按实际代码证据归纳。

终端运行服务时 Ctrl+C 可停止。启动器后台运行时，可在任务管理器根据启动时 PID 结束对应 Node 进程。
